# RoboMotion 3D – Interactive Robotic Arm Simulation

RoboMotion 3D is a web-based robotic arm simulation and control platform that allows users to visualize and control a 3D robotic arm through an interactive interface.

## 🌐 Live Demo
[View RoboMotion 3D](https://robomotion-3d.netlify.app/)

## ✨ Features
- Interactive 3D robotic arm visualization.
- Individual joint angle controls.
- Joystick-based movement.
- Gripper open and close controls.
- Preset movements: Pick, Place and Inspect.
- Adjustable movement speed.
- Emergency Stop functionality.
- System status and movement history.

## 🛠️ Technologies Used
- React.js
- TypeScript
- Three.js
- React Three Fiber
- Drei
- Zustand
- Vite

## 🚀 Run Locally

**1. Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**2. Navigate to the project**
```bash
cd robomotion-3d
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the application**
```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

**5. Build for production**
```bash
npm run build
```
